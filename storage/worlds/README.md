# Wordsmith 3D Worlds Storage (`storage/worlds/`)

Este directorio está diseñado para almacenar archivos 3D locales que podés probar directamente en la aplicación.

### Formatos soportados:
- **`.spz` / `.splat`**: Archivos de 3D Gaussian Splatting (formato estándar de World Labs Marble).
- **`.glb` / `.gltf`**: Mallas y entornos 3D en formato GLTF binario.

### Cómo usarlo:
1. Copiá cualquier archivo `.spz` o `.glb` dentro de esta carpeta (por ejemplo: `parque.spz` o `ciudad.spz`).
2. Abrí la aplicación en el navegador.
3. En el selector superior de **"Mundos Guardados"**, vas a ver aparecer automáticamente tus archivos locales listos para cargar y explorar con **WASD**.
