# Wordsmith 3D Models Storage (`storage/models/`)

Este directorio está diseñado para almacenar modelos 3D locales en formato **GLB** (por ejemplo, modelos exportados desde **Tripo 3D Studio**, Blender u otras herramientas).

### Formatos soportados:
- **`.glb`**: Modelo 3D binario GLTF (formato estándar de exportación de Tripo 3D).
- **`.gltf`**: Modelo 3D GLTF estándar con recursos incrustados.

### Cómo usarlo:
1. Colocá tus archivos `.glb` generados o exportados de Tripo 3D directamente dentro de esta carpeta (por ejemplo: `taza.glb`, `personaje.glb`, `dragon.glb`, etc.).
2. Abrí o recargá la aplicación en el navegador.
3. En la barra superior, hacé clic en el botón de **"Modelos 3D"** / **"Agregar Modelo"**.
4. Seleccioná cualquier modelo de la lista y se insertará automáticamente en el mundo 3D cargado frente a tu posición actual.
